OptiFlowz API Reference

Complete Express API reference for authentication, video delivery, playlists, quizzes, moderation, reports, and user-facing platform features.

The OptiFlowz backend exposes REST endpoints for a video platform built around users, video assets, watch progress, playlists, comments, people, quiz attempts, certificates, and analytics.

Use the cards below to open a focused route group. Endpoints marked as protected require a Bearer JWT token, while moderation endpoints require an admin or uploader role.

Endpoints

A

Auth

Register, login, OAuth, profile updates, password reset, and profile images.

 V

Videos

Search, playback details, upload initiation, progress, reactions, history, and recommendations.

 M

Video Moderation

Video metadata, thumbnails, subtitles, Mux track management, and generated details.

 P

Playlists

Playlist search, featured lists, saved playlists, and playlist video browsing.

 Q

Quizzes

Quiz management, questions, access rules, attempts, answers, certificates, and scoring.

 U

People

Speaker and chair profiles, search, sorting, profile images, and admin maintenance.

 C

Comments

Comment posting, replies, editing, deletion, and reactions.

 H

Channels

Channel details, published videos, and public playlist collections.

 R

Reports

PDF analytics export for video platform reporting.

General rules

  • The local backend base URL is http://localhost:4000.
  • JSON routes use the header Content-Type: application/json.
  • Protected routes use the header Authorization: Bearer <jwt-token>.
  • Routes marked as Admin require a user with the role admin or uploader.
  • Routes marked as Optional also work without a token, but return personalized data when a token is provided.
  • Upload routes use multipart/form-data, usually the field file.

Auth /api/auth

POST/api/auth/registerPublic

Registers a new user and returns a JWT token.

Body

{
  "email": "user@example.com",
  "password": "password123",
  "full_name": "Full Name",
  "description": "",
  "eaes_member": false
}

Validation

Email must be valid, password must be at least 8 characters, and full name is required.

Response

{
  "user": { "email": "...", "role": "user" },
  "token": "jwt"
}
POST/api/auth/loginPublic

Logs a user in with email and password.

Body

{
  "email": "user@example.com",
  "password": "password123"
}

Note

The password is verified against a bcrypt hash.

Response

{
  "user": { "email": "...", "role": "user" },
  "token": "jwt"
}
POST/api/auth/passwordResetRequestPublic

Generates a password reset token and sends it through the external n8n webhook.

Body

{ "email": "user@example.com" }

Limit

This route is rate-limited to prevent abuse.

Response

{
  "message": "If that email is registered..."
}
POST/api/auth/passwordReset/verifyPublic

Checks whether the reset token is valid and not expired.

Body

{
  "email": "user@example.com",
  "token": "ABC123"
}

Validation

The token is a short code, and email must be valid.

Response

{ "valid": true }
POST/api/auth/passwordResetPublic

Changes the password when the reset token is valid.

Body

{
  "email": "user@example.com",
  "token": "ABC123",
  "newPassword": "newPassword123"
}

Effect

The new password is hashed and the token is marked as used.

Response

{ "message": "Password reset successful" }

OptiFlowz Backend Overview

High-level map of the Express backend that powers the OptiFlowz video platform.

The backend is organized as a modular Express API. The application configures CORS, request parsing, Mux webhook parsing, route registration, not-found handling, and centralized error handling before exposing the platform under /api.

Core modules cover authentication, video discovery and playback, video and playlist moderation, people profiles, comments, channels, quizzes, certificates, and PDF analytics reports. Most public browsing endpoints accept optional authentication, while user actions and moderation workflows rely on JWT authentication and role checks.

Request Flow

Requests enter through the Express app, pass through CORS and JSON parsing, then fan out to module routes registered from src/routes/index.js.

Media Pipeline

Video upload, playback, thumbnails, subtitles, generated chapters, and webhook updates are handled through Mux and moderation services.

Learning Layer

Quizzes connect videos and playlists with access rules, attempts, answers, grading, and certificate generation.
